# Terminology (Single Source of Truth)

- **Аукцион** — сущность грузового аукциона. Имеет UUID, номер заявки, тип, статус,
  маршрут, груз, параметры торгов.
- **Тип аукциона** — `Request`, `Up`, `Down`, `FixPrice`. Определяет механику торгов.
- **Статус аукциона** — текущее состояние аукциона (активен, завершён, отменён и т.д.).
- **Торговый статус пользователя** — `Leading`, `Losing`, `Winner` и т.д. Показывает
  позицию текущего пользователя в торгах.
- **Ставка (Bet)** — предложение цены от перевозчика. Имеет цену с/без НДС, перевозчика,
  место в рейтинге, признак победителя, признак отмены.
- **Маршрут** — последовательность точек погрузки и выгрузки. Содержит города, даты,
  адреса (могут быть скрыты).
- **Груз** — описание перевозимого: название, вес, объём, тип кузова.
- **can_set_bet** — флаг в DTO, определяет доступность формы установки ставки.
- **hide_bets_history** — флаг в DTO, скрывает историю ставок.
- **hide_points_address_and_contacts** — флаг в DTO, скрывает адреса точек и контакты.
- **no_view_cargo_price** — флаг в DTO, скрывает цену груза.
- **OpenAPI-контракт** — схема `openapi.auctions.v0.json`. Единственный источник правды
  для API: структуры запросов/ответов, enum-значения, nullable-поля, ошибки.
- **MSW-store** — in-memory хранилище состояния моков. Обновляется после мутаций
  (установка ставки меняет текущую цену, статус пользователя, список ставок).

## Deprecated terms (do not use)

- "Заказ", "заявка" (в контексте ставки — использовать "ставка").
- "Тендер" — использовать "аукцион".
