# Product Overview

SPA для работы с грузовыми аукционами по OpenAPI-схеме. Фронтенд-проект, который
обеспечивает просмотр списка аукционов, детальную информацию, историю ставок и
установку своей ставки.

## What it IS

- Single Page Application для грузовых аукционов.
- Core value: **удобная работа с аукционами — список, детали, ставки**.
- Источник правды — OpenAPI-схема `openapi.auctions.v0.json`.

## What it is NOT

- Не backend-проект. Backend не пишется — только MSW-моки.
- Не полноценный production-сервис — это тестовое задание с фокусом на архитектуру
  и качество кода.

## How it works (high level)

- Пользователь открывает список аукционов с фильтрами и пагинацией.
- Пользователь переходит на детальную страницу аукциона.
- Пользователь может посмотреть историю ставок.
- Пользователь может установить свою ставку через форму.
- Все API-вызовы идут через MSW-моки в dev-режиме.

## Key features

- Список аукционов: пагинация, фильтры, skeleton/empty/error states, prefetch.
- Детальная страница: полная информация об аукционе, организатор, контакты, маршрут,
  груз, условия, параметры торгов.
- История ставок: список ставок, рейтинг, победители, отмена.
- Установка ставки: форма с валидацией, mutation, инвалидация кэша, toast.
