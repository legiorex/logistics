# Review Guidelines — Root

## Critical Areas

- Manual edits to `src/shared/api/generated/` are forbidden — only regenerate from the OpenAPI spec via `pnpm generate:api`.
- MSW mocks (`src/shared/api/mocks/`) must match the OpenAPI contract exactly: structures, enum values, nullable fields, error codes.
- FSD layer boundaries must be respected — no imports from upper layers into lower ones.
- Changes to `src/routeTree.gen.ts` are forbidden — it is auto-generated by TanStack Router.
- Search params must use Zod validation with safe fallback values.

## Conventions

- All functions and methods must have explicit return types — `any` is prohibited.
- React components must be functional with hooks; class components are forbidden.
- Imports must use `@/` alias for `src/` paths.
- shadcn/ui components go in `@/shared/ui`; utilities in `@/shared/lib`.
- All forms must use React Hook Form + Zod validation.
- All API calls must go through the generated Orval client (`react-query` hooks).
- DTO flags (`can_set_bet`, `hide_bets_history`, `hide_points_address_and_contacts`, `no_view_cargo_price`) must be handled explicitly in UI.

## Ignore

- Auto-generated files: `src/shared/api/generated/**`, `src/routeTree.gen.ts`, `dist/`, `node_modules/`.
- Lock files (`pnpm-lock.yaml`) — only review when dependencies change.
- `public/mockServiceWorker.js` — MSW worker script, auto-generated.

## Performance

- Flag any TanStack Query calls missing proper cache invalidation after mutations.
- Watch for missing `staleTime` / `gcTime` configurations that could cause excessive refetching.
- Ensure prefetch is configured on list→detail navigation (intent/hover).
- Flag any missing pagination handling in list queries.
- Ensure skeleton/empty/error states are present for all async data displays.
