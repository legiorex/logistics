# Карточка аукциона

Карточка аукциона должна показывать:

- номер заявки
- тип аукциона: Request, Up, Down, FixPrice
- статус аукциона
- торговый статус пользователя: Leading, Losing, Winner, etc.
- маршрут погрузка → выгрузка
- даты погрузки/разгрузки
- груз: название, вес, объём, тип кузова
- текущую цену, цену за км, шаг ставки
- флаг "моя ставка есть / нет"
- primary action: "Сделать ставку", "Изменить ставку", "Смотреть ставки" или disabled-состояние
